# Wheat-Crossing-Block
Aplicativo para coleta de espigas disponíveis no BC.

O código do aplicativo está na branch [feat/coleta-offline](https://github.com/WheatResearchGDM/Wheat-Crossing-Block/tree/feat/coleta-offline).

- [Abrir o código das telas e da coleta](https://github.com/WheatResearchGDM/Wheat-Crossing-Block/tree/feat/coleta-offline/src)
- [Gerar e baixar APK Android pelo Actions](https://github.com/WheatResearchGDM/Wheat-Crossing-Block/actions/workflows/android-apk.yml)
- [Instruções de compilação e instalação pelo GitHub](https://github.com/WheatResearchGDM/Wheat-Crossing-Block/blob/feat/coleta-offline/docs/GITHUB_ACTIONS.md)

Para gerar o APK, abra o workflow, clique em **Run workflow** e mantenha `source_ref` como `feat/coleta-offline`. Após a conclusão bem-sucedida, baixe o arquivo em **Artifacts**, extraia o ZIP e instale o APK no Android.
